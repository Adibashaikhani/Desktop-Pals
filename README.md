# 🐰 Desktop Pals

**Your little companions, right on your desktop.** 💗

Desktop Pals is a cozy desktop companion app that brings adorable virtual pets to your Windows desktop. Designed with a soft, playful aesthetic, it makes your workspace feel a little warmer while you study, work, or relax.

## ✨ About the Project

Desktop Pals is a desktop companion experience built to make everyday computer use a little more delightful. The goal is to create lightweight, friendly pets that live on your desktop without getting in the way of your work.

## 🌸 Features

- 🐰 **Adorable desktop companions** — cute pets that bring personality to your workspace.
- 🖥️ **Desktop-friendly design** — a compact, frameless window designed to stay out of your way.
- 💗 **Soft pastel aesthetic** — a cozy visual style with pink and mint accents.
- ✨ **Animated interactions** — expressive movements and activity-based reactions.
- ⚙️ **Customizable settings** — adjust supported pet behavior and appearance.
- 🔒 **Privacy-conscious design** — activity awareness is intended to use system idle time rather than capture the text you type.

> Features may change as development continues. Check the current release for the latest functionality.

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/) — use a version supported by the project's dependencies
- npm, included with Node.js
- Git, if cloning the repository

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Adibashaikhani/desktop-pals.git
   ```

2. Navigate into the project:

   ```bash
   cd desktop-pals
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development environment:

   ```bash
   npm run dev
   ```

> If the project uses different scripts or repository names, update these commands to match your `package.json` and GitHub repository.

## 📦 Building for Windows

To create a production build:

```bash
npm run build
```

To create the Windows Store package, if the project has the configured script:

```bash
npm run dist:store
```

Build output and packaging requirements depend on the project's current Electron Builder configuration.

## 🔐 Privacy

Desktop Pals aims to be a friendly, privacy-conscious desktop companion. Activity awareness should rely on system idle information rather than collecting the actual text users type.

For the current implementation, review the app's permissions, dependencies, data storage, and network behavior before making definitive privacy claims.
